F-statistics: testing population relationships¶

Purpose. -statistics turn allele frequencies into a small set of numbers that answer concrete historical questions: how much drift separates two populations, whether a third is a mixture of them, whether four populations form a tree, and in what proportions a target descends from a set of sources. They are the workhorse of ancient DNA analysis because they need only allele frequencies — no phasing, no haplotypes, and they tolerate low coverage.

What you will do

  • read precomputed statistics and view them as a distance matrix
  • use admixture to test whether a population is a mixture — and see that a negative value is evidence, while a positive one proves nothing
  • use outgroup to measure shared drift with a reference population
  • use for the treeness and symmetry tests
  • fit admixture proportions with qpAdm and judge whether the model is acceptable

The data. A subset of the Allen Ancient DNA Resource (AADR): 1,646 individuals in 98 populations — 53 modern and 45 ancient.

  • Modern populations carry the suffix .HO: genotypes from the Human Origins SNP array.
  • Ancient groups carry suffixes for age group or culture — _HG for hunter-gatherers, and so on — so the label tells you what a group is.

The statistics are precomputed for all population pairs, with blocked jackknife standard errors. Those standard errors are what make the tests possible: an -statistic without an error bar cannot be interpreted.

Before this do MDS and PCA by hand. After this, admixture graphs builds on the same statistics.

2. statistics¶

statistics provide a distance measure based on genetic drift between pairs of populations. In admixtools, pre-computed data is organized in an array with those distances between each pair of populations, separate for each genomic block.

We can average the pairwise statistics across all blocks to obtain genome-wide distances, and use them to visualize genetic structure between the populations. Here we do that for all modern populations in the dataset, using a heatmap and a neighbor-joining tree.

In [6]:
## heatmap of f2 distances between modern populations
pops <- sample_info %>%
    filter(age_group == "modern") %>%
    distinct(group_id) %>%
    pull(group_id)

f2_pop <- apply(f2_data[pops, pops, ], 1:2, mean) # average across all blocks
diag(f2_pop) <- NA
heatmap(f2_pop, scale = "none", col = viridis(100), cexCol = 0.5, cexRow = 0.5)

## Neighbor-joining tree of f2 distances, root with South African hunter-gatherer population
tr <- nj(f2_pop) %>%
    root(outgroup = "Ju_hoan_North.HO")

plot(tr, cex = 0.5, font = 1)

3. statistics¶

In this section we will explore the two main applications of statistics: Testing for evidence of admixture, and measuring shared genetic drift.

3.1. Admixture ¶

Admixture statistics of the form (X;A,B) test whether there is evidence for admixture in population X. IF (X;A,B) < 0, we can conclude that X is admixed with respect to sources related (possibly deeply!) to populations A and B. To gauge whether the test statistic is significantly negative, a block jacknife across all blocks is used to estimate standard errors and a corresponding Z-score.

In the following example, we use the qp3pop function to test whether there is evidence for admixture in African Americans, between Yoruba from Nigeria as one source and all other modern populations as other source.

In [8]:
## Testing for admixture in African Americans

    filter(age_group == "modern") %>%
    distinct(group_id) %>%

## We use qp3pop here with
## African Americans as the admixed population (pop1).

3.2. Outgroup ¶

In outgroup statistics of the form (O;A,B) the target population X from the admixture test is replaced by a known outgroup population O to (A,B). The result of (O;A,B) is then are a measure of the genetic drift shared between A and B from their common ancestor to the outgroup O.

In the following example, we use the qp3pop function to test estimate genetic drift shared between Sardinians and other modern populations, using an African hunter-gatherer population (Mbuti) as outgroup.

4. statistics¶

In this section we will explore the two related applications of statistics: Testing for treeness and symmetry tests.

4.1. Treeness test¶

Statistics of the form (A,B;C,D) test whether four populations A,B,C,D are related through a simple unrooted tree. If (A,B;C,D) = 0, and the results for the other two configurations are (A,C;B,D)>0 and (A,D;B,C)>0, a simple tree ((A,B)(C,D)) without gene flow is supported. If all three configurations are different from zero, a simple tree is rejected and gene flow must have occured.

D-statistics are closely related to these statistics, differing only by a scaling factor.

In the following example, we use qpdstat to test whether two African populations (Mbuti hunter-gatherers and Yoruba from Nigeria) form a clade with respect to two ancient European populations: Yamanaya pastoralists from the Eurasian Steppe (Russia_Samara_EBA_Yamnaya) and early European farmers (Germany_EN_LBK)

5. qpAdm¶

In the final part of the exercises we will explore how to estimate admixture proportions using qpAdm, a phylogeny-free approach based on sets of statistics between three groups of populations:

  • a "target" population for which we want to estimate admixture proportions
  • "source" or "left" populations which can potentially contribute ancestry to the "target"
  • "outgroup" or "right" populations, differentially related to the "source" and "target" groups

The choice of "right" populations has important impact on the results, as differentially shared genetic drift with both "source" and "target" populations are the signal that qpAdm uses to test for admixture and estimate proportions.

In the following example, we explore the established three ancestral population model of Europe (hunter-gatherers, farmers and Steppe) on modern English as a target.
